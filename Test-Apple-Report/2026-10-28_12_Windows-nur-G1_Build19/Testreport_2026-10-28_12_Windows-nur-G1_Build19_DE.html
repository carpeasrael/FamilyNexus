1hochV-04Windows-Build startet nicht. In LocalReminderScheduler.initialize (lib/data/platform/reminder_scheduler.dart, ca. Das Plugin wirft beim Start Invalid argument(s): Windows settings must be set when targeting Windows platform. (aufgerufen aus bootstrap.dart:79). Die App zeigt dazu die irreführende Seite „Lokale Daten nicht lesbar“; „Lokale Daten zurücksetzen“ hilft nicht. Belegt für den lokalen Build 1.2.1 (19) aus f4c358c. Der frühere Lauf (Release Build 16) zeigte dasselbe Bild; ob dort dieselbe Ursache vorliegt, wurde nicht geprüft. Mit windows: WindowsInitializationSettings(appName: 'FamilyNexus', appUserModelId: 'de.inneso.FamilyNexus', guid: '<feste GUID>') startet die App (Diff in logs/windows-startfix.diff). Die Meldung „Lokale Daten nicht lesbar“ sollte außerdem zwischen Datenbankfehler und anderen Startfehlern unterscheiden. Es besteht kein Zusammenhang mit VM/Datenbank, entgegen der Vermutung im Lauf vom Vormittag.
