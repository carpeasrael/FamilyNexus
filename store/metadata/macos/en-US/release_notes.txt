New in 1.2.1:
• Screenshots and screen recordings are allowed on the Mac; the “Screen protection” switch is not shown there.
• Signing in through the provider's website (e.g. matrix.org) works again. Before, the jump to the page already failed.
• matrix.org stays the default provider. Previously, after signing in with a full ID (@name:server) or an invitation on another server, that server was shown as the default.
• Settings → About the app: overview of where data is stored locally, and reports of all data stored locally and online to view, copy or save.
• Settings → Account → “Delete account”: permanently delete the account at the provider, then all data on the device.
• Settings → Emergency key and devices: create a new emergency key. When setting up a new account, the key is now always shown.
• The version display includes the build number.
• After “Delete all local data” or “Delete account” the app starts again with the welcome screen instead of sign-in.
• Fixed: “Write a message” reliably opens the private chat; events: the end moves with the start; images in the chat can be saved; localized dates for tasks; further fixes from testing.
• Also: syncing offers “Try again” after 30 seconds; a wrong password when deleting the account is reported clearly; verification emojis are named in the app language; “Upcoming events” are sorted by start; Mac: Enter sends messages (Shift+Enter = new line).
• Fixed: the notice “Report sent.” disappears by itself again; after “Shared → Private” the event detail page shows the event instead of “Deleted”; hints for the username are shown in full.
• Fixed: rejected join requests are reported within seconds instead of minutes; event details show the new time right after editing; “Unread messages” counts only readable messages; messages of deleted members show the name; “Link copied.” appears in the invite dialog; Enter saves in dialogs; notifications can be allowed via “Open settings”.
